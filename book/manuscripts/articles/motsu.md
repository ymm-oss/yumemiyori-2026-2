# 自律型AIエージェント、使っていますか？

ここ最近の進歩をみると、自律型AIエージェントは、ただ質問に答えるものからユーザーの代わりに作業を進めるものへと役割が広がりました。メールの下書きや予定の調整を指示してやってもらうだけでなく、自律的に動いて先回りするようになってきています。ユーザー側はそろそろ何をするのかな、という勢いです。

最近は、これらをどうやって使っていこうかと楽しみに生きています。自分自身の整理も兼ねて、自律型AIエージェントのサービスをどう使っていくのがいいのかを書いていこうと思います。Grok Bot中心で書きますが、Dotsだけは契約していないので、わかる範囲の内容にとどめておきます。

価格と機能は、すべて2026年10月時点の公式ページに基づいています。価格もプランの中身も変わりやすい分野なので、購入や契約の前には公式URLで必ず最新の情報を確かめてください。

## いまの自分にとっての使い分け
今はどんなサービスがあり、どう使っているのかをざっくりとまとめます。

### 比較対象
- Grok Bot：役割ごとに複数のBotを並行して動かしており、ほぼなんでもやってもらうメイン。
- Muse：GrokとHarkの中間の立ち位置とInstagram徘徊用。
- Hark：生活のオペレーションを担い、クラウドPC（Handoff）で作業を代行。ダッシュボード機能とかあるのでパッと見たいものをまとめる用。
- Cue：Grok Botのサブの立ち位置。
- Dots：ChatGPT Pro の中に常駐するエージェント、Proプラン以上のため、記載のみ（早くPlusユーザーにも解放してほしいなと）

### 比較表（2026年10月時点）
| サービス | 向いている使い方 | 選ぶ前に確認したいこと |
| --- | --- | --- |
| Grok Bot | 情報収集、メール、開発の振り分けなどを、役割別のBotに分けて並行させたい人 | CursorやGrokとの使用枠は定期実行や並列作業が増えた場合になくなりやすい |
| Muse | 生活の予定、メール、買い物などを、まず1つのエージェントにまとめて依頼したい人 | 無料枠には使用上限がある |
| Cue | エージェントごとに役割や連絡先を持たせ、人や他のエージェントとのやり取りを試したい人 | 招待制で、利用時にクレジットを消費する |
| Hark | メールや予定など生活側の作業を依頼し、天気や進捗をパネルでまとめて見たい人 | 使用上限があり、自動チャージを有効にすると追加料金が発生する |
| Dots | ChatGPT・Work・Codexを使い、調査や開発など継続する仕事を1つのエージェントに見てほしい人 | WorkやCodexに依頼した作業は、それぞれの使用枠を消費する |

## 各サービスの紹介と自分なりの使い方
ざっくりと書いていて、結局どれも似ていると感じる人も多いはずです。筆者も分ける必要があるのかと迷う時があり、どれか1つにまとめてもいいなと感じています。ただ、サブスクリプションに含まれていたり、無料でクレジットがもらえたりして使い分けができるので、試行錯誤している途中です。

### Grok Bot
Grok Bot は、複数のBotをチームメイトのように並行して24時間動かし、クラウド上のコンピュータでアプリやWebにログインして作業してくれます。仕事のやり方（ルーチン）を覚え、承認が必要な場面では人に戻ってくる、という作りです。例として挙がっている役割は、営業のアウトバウンド、バグの再現、アカウントの健全性チェック、Chief of Staff など、業務・営業・開発寄りのものが中心となっています。

公式が1つの会社をつくる配信をしていましたが、一般ユーザーは会社をつくらないので、まずは1つのBotを立ち上げて、色々と投げてみるのがいいです。そこから分けたほうがいいなと感じてきたら、専門家としてどんどん切り分けていくと自然と分業化できます。

自分の例だと、次のような担当です。

- AIやクラウド、他にも関心のある情報収集担当
- 同人誌の情報収集と下書き執筆担当
- セキュリティ担当
- コーディングのオーケストレーション担当
- グルメ情報収集担当
- メール担当

これらがいつも動いています。XにはWebで調べても見つかりづらい面白い情報が多くあるので、そこから拾えるというのが一番の強みです。Dotsほどではないものの、コーディングもできます。ただ、Botにコーディングさせると使用量を消費するので、Claude等にコーディング依頼をさせて、Botはオーケストレーションを担当することでGrokの使用量を節約できます。専用Botをチームとして集めて議論させることもできるので、複数意見を聞くためにそれぞれに質問を投げるというのも不要です。
メールアドレスを独自で取得できて、bot同士で使い回せるので登録やメールのやり取りもできます。

### Muse
Muse は Meta の個人向けAIエージェントです。質問に答えるだけでなく、メールの送信、旅行の予約、フォームの入力、買い物、目標の計画と継続までを手伝う、と公式に説明されています。専用のクラウドPC（Muse Secure VM）で動くので、アプリを閉じても作業は続き、送信や購入の前には承認を求めます。
Metaとの連携が得意なので、InstagramやThreadsといったSNSから情報を収集したり、日常のタスクを振ったりすることがほとんどです。今回紹介する中で無料で気軽にはじめられるので、どんなものかを試すのにちょうどいいです。

| --- | --- | --- |
| Free | \$0（使用上限あり） | 具体的なトークン数（公式未確認） |
| Power | \$20 | 500M Muse tokens / 週 |
| Maximum | \$100 | 3B Muse tokens / 週 |

### Cue
Cue（Cue OS）は、Plus One Labs が運営するエージェントです。エージェントが独自のidentity（メール・電話・ウォレットなど）とコンピュータを持つ、という製品説明が特徴です。電話番号を取得できるのが他にはない大きな特徴ですが、執筆時点では電話番号の新規申請が停止しています。使い勝手はGrok Botに近いです。
Manusを使っているのでGrok Botとほぼ同じ機能をもたせつつ、使用量を節約したい時にこっちを使います。あとは生活情報（コンビニのクーポンとか）はこちらに収集を寄せています。取得した情報は全てNotionへと格納させています。

| Premium | \$200 | 20,000 |

### Hark
Hark（Hark Pro）は、生活の「OS」を名乗る個人向けアシスタントです。食材の注文、メール、スケジュール、Slack、ドキュメント、プロジェクトの追跡といった日常の作業を扱います。中心となるのは Handoff という機能で、クラウド上のコンピュータでWebサイトにサインインして操作します。Panels（小さなダッシュボード）、Action Buttons、Scheduled Tasks などで、作業の状況を見える形にするのも特徴です。公式ではコードの最適化よりも日常の作業寄りだと説明しています。

Museと同じようなもの、というのが今の段階での感想ですが、より個人の生活に近いタスクをやってもらいやすいです。あとはホームにパネルとして情報を載せられるので複数地点の天気予報（競馬をやっていると開催地の天気を一気に知りたい）、今やっているキャンペーン、メールから得たToDo等を1つの画面でみることができます。これだけは他にもないので重宝しています。

### Dots（紹介のみ）
Dots は、ChatGPT の中に常駐するOpenAIのエージェントです。クラウドPCとブラウザ、接続アプリを使い、目標に向けて作業を続け、フィードバックから学びます。公式の例は、顧客フィードバックからの修正PR、ローンチ資料の更新、研究データの再分析、コンテンツ制作、提案書の更新などです。ChatGPT のほか、Slack や Teams からも呼べます。

## 用途別の向き不向きについて
やれることはほぼ同じでも、UIや実際にできることは案外異なっています。自分がエージェントに対して何を求めているかで使い分けが必要なので、できれば一通り触りたいところですが、なんとなくこういった用途ならこれを使うというのを書いてみます。

### 単一 or 複数 botで使いたい
役割の違うbotを並行して常駐させたいなら、Grok BotかCueです。他は1つの画面で幾つもチャットをやり取りするので、あとから何をしたのかを追うのが面倒に感じます。一方、管理が面倒という人にとっては、複数のbotを作るのも手間なので、好みによるかなと思います。見た目の問題なので、作業をふるだけなら特に大きな差はないですが、何を依頼したのかが時々わからなくなります。

### 生活や事務を代わりに進めてほしい
メール、予約、買い物、予定の管理といった生活側の作業なら、Muse と Hark が候補になります。Muse は目標の計画と継続まで手伝う「スチュワード」寄り、Hark は Handoff でサイトを操作し、Panels で状況を見える形にする「オペレーション」寄り、という違いがあります。ちょっとしたコンシェルジュ的な扱いをしやすいので、複数botに管理させなくてもいいので、気楽に依頼でき、あとは勝手にやってくれます。

### 調査・資料・開発の作業を続けてほしい
すでに ChatGPT Pro以上を使っている人には、Dots が自然な選択肢になります。公式の例は、修正PR、資料の更新、研究データの再分析など、続けて取り組む作業が中心です。Codex や ChatGPT Work と連携できるのも、開発や資料作りに向いている点です。仕事で使えるなら真っ先に候補になりますね。
Grok Botも専門botとして役割を与えればそれなりに使えますし、他のサービスでもできないわけではないです。

## 外部サービスとの連携がこれまで以上に重要になる
これらのbotの便利さは、何とつながっているかでかなり変わります。Notion は情報の置き場として便利ですが、用途によっては Gmail・カレンダー・Slack・GitHub・Sheets など、Notion 以外の連携のほうが先に効く場面もあります。NotionではなくObsidianという人もいますし、Googleスプレッドシートという人もいます。ここで大事なのはどのサービスからでも接続できる環境があること。ログインのし直しや情報のまとめ先が散らかっているとあとから不便になるので、ここは早めに統一しておくべきです。

### 連携の実例表（2026年10月時点）
| サービス | 公式で確認できたコネクタ・接続 | 実例・注意 |
| --- | --- | --- |
| Grok Bot | Gmail（検索・読取、下書き・送信、ラベル。メールボックスは同時に1つ）、Slack（接続ユーザーとして投稿）、Google Calendar（読取、作成・更新、空き確認、招待への応答）、Google Sheets / Drive、1Password（ログイン代行。Botは値を見ない）、X プラグイン（X API credits が必要）、Bot専用のメールアドレス | 実例は下記。Zoom 接続は既知の不具合（error 4700）が未解決と公式に記載あり |
| Muse | Connectors（ヘルプの例：Gmail、カレンダー）、Meta系（Facebook / Instagram / Threads は Accounts Center で自動接続）、Custom Connector | 重要な操作（メール送信など）は初期設定で承認が必要。読取専用にできるコネクタあり。コネクタの完全一覧は公式未確認 |
| Cue | 公式 Connectors 9種：Gmail、Google Calendar、Google Drive、Slack、GitHub、DigitalOcean、OpenAI Codex、LinkedIn、X | 他人・他エージェント起点の作業では、送信やカレンダー変更などにオーナーの承認カードが出る。チャット（Discord / Telegram / WhatsApp / Feishu）は CLI という別経路 |
| Hark | Services：Google Workspace、Microsoft 365「など」。Handoff でクラウドPC経由で多数のサイトを操作 | Slack の追跡や docs 作成は製品説明に登場。「and more」の中身は公式未確認 |
| Dots | ChatGPT Plugins／接続アプリ、Slack・Teams、個人メール、ローカルPC（初期設定はオフ） | 自分から進める調査では、接続アプリの読取専用ツールのみ |

### 情報の置き場を Notion に寄せる
情報の集約先として使いやすいのがNotionです。Obsidianよりも非エンジニアには使いやすいUIなのと、Notion AIもあるので、双方からAIを使うことができます。違う情報源から同じテーマの内容を保存する場合はそれぞれのサービスだけで保持していると探すのが面倒と感じます。
エンジニアが興味のあるアップデート情報、ブックマークだけして後から読むリンク、グルメ情報といったものを定期的に集めてNotionに入れておき、後から検索することでWeb検索よりも欲しいものを得ることができるようになります。他にもエージェントの設定情報を入れておき、後から別サービスに移管するときにも読み込ませることで1つのサービスにこだわらなくても良いようになりました。

### 認証情報やパスワードは1Passwordを使う
MuseやGrok Botが最近になって接続できるようになりました。Googleの認証を使ったとしても予約したいサイトの操作をさせてもパスワードやカード番号が必要になるので入力はなるべく避けていました（Vault機能で独自に保存してくれるGrok Botは信用していましたが）。1Passwordと連携できればこれらの情報を入力しなくてもサービスにログインできるようになったので、パスワード漏洩等の心配も当初よりはだいぶ減ったかと思います。
ちなみに本筋とは少しそれますが、エージェントがログインできるようになったので、1Passwordから脆弱性のありそうなパスワードを自動で変更したり、不要なサービスやメルマガを依頼して解除させることもやりやすくなりました。これまでCodexにメール整理を依頼していたのをエージェントに作業を委譲して定期的に見てもらうようにもしましたので、アカウントの整理や不要なメールがなくなっていくのでスッキリしていきます。

### 他AIサービスとの使い分けについて
AIを使っているとタスクやスケジュールといった機能があるので、どう使い分けるのか悩みます。個人的には一回きりの実装や大きなコード変更は、Codex・Cursor・Claude Code など実装寄りのツールに任せ、botは常駐の振り分け・進捗の追従・承認がいる雑務に寄せる、という分け方でやっています。

## よき自律型AIエージェントライフを
今だいぶホットな話題のところなので、これから機能が追加されていくと思います。自分が抱え込んでいるものをAIが代行してくれるので、嘘偽りなく、秘書やコンシェルジュとして身近な存在になるはずです。是非興味のあるサービスから使ってみましょう。
